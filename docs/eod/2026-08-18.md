Project/Focus: Remedy Scribe — Tech Stack Decision & End-to-End Scaffolding

🎯 PROGRESS & IMPACT

· Challenge: The PRD and roadmap were approved but nothing was built, and the compressed timeline (pipeline work starting Week 1, no vendor bake-off) meant the architecture had to be committed to before either AI vendor could be validated — so a wrong structural bet would surface only after real engineering time was sunk.
· Action/Solution: Locked the stack against each P0 requirement (React Native/Expo + FastAPI + Postgres + Celery/Redis + S3-compatible storage), scaffolded the monorepo, and built the backend vertical slice: seven data models, JWT + TOTP auth, the four-state note lifecycle, name-and-birthdate patient matching, and an append-only consent ledger. Wired the transcription pipeline behind swappable provider interfaces so the Luna→Haiku fallback is a config flag rather than a rewrite.
· Result: 1,930 lines of Python across 54 files, 9 passing tests, migrations applied to live Postgres, and the running server driven end-to-end with curl through login → patient match → encounter → consent. Consent-ledger immutability is enforced by a Postgres trigger, verified by hand: UPDATE and DELETE both raise.

✅ OUTCOME

· Working foundation, not a diagram: every architectural claim in the stack doc was executed rather than asserted — the pipeline's swap-a-vendor requirement, the no-skippable-states rule, and the immutable ledger all exist as running, tested code. Two reference docs published: a production checklist and a codebase walkthrough.
